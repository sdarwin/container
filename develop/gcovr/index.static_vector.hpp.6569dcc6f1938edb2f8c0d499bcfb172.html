145 //!
146 //!@brief A variable-size array container with fixed capacity.
147 //!
148 //!static_vector is a sequence container like boost::container::vector with contiguous storage that can
149 //!change in size, along with the static allocation, low overhead, and fixed capacity of boost::array.
150 //!
151 //!A static_vector is a sequence that supports random access to elements, constant time insertion and
152 //!removal of elements at the end, and linear time insertion and removal of elements at the beginning or
153 //!in the middle. The number of elements in a static_vector may vary dynamically up to a fixed capacity
154 //!because elements are stored within the object itself similarly to an array. However, objects are
155 //!initialized as they are inserted into static_vector unlike C arrays or std::array which must construct
156 //!all elements on instantiation. The behavior of static_vector enables the use of statically allocated
157 //!elements in cases with complex object lifetime requirements that would otherwise not be trivially
158 //!possible.
159 //!
160 //!@par Error Handling
161 //! If `throw_on_overflow` option is true (default behaviour), insertion beyond the capacity result
162 //! in throwing bad_alloc() if exceptions are enabled and or calling throw_bad_alloc() if not enabled.
163 //! If `throw_on_overflow` option is false, insertion beyond capacity results in Undefined Behaviour.
164 //!
165 //! out_of_range is thrown if out of bounds access is performed in <code>at()</code> if exceptions are
166 //! enabled, throw_out_of_range() if not enabled.
167 //!
168 //!@tparam T The type of element that will be stored.
169 //!@tparam Capacity The maximum number of elements static_vector can store, fixed at compile time.
170 //!@tparam Options A type produced from \c boost::container::static_vector_options. If no option
171 //! is specified, by default throw_on_overflow<true> option is set.
172 template <typename T, std::size_t Capacity, class Options BOOST_CONTAINER_DOCONLY(= void) >

179 #endif
